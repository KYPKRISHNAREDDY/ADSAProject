## 💻 OR: Manual Method

### Step 1: Install Python packages (one-time)
```cmd
pip install matplotlib pandas seaborn
```

### Step 2: Compile
```cmd
g++ hospital_graphs.cpp -o graphs.exe
```

### Step 3: Run simulation
```cmd
graphs.exe
```

### Step 4: Generate graphs
```cmd
python generate_graphs.py
```

### Step 5: View results
```cmd
cd graphs
start REPORT.html
```
