1. Compile automatically
2. Generate data
3. Create HTML dashboard
4. Open in your browser automatically! 🎉

---

## 💻 OR: Manual Method

### Step 1: Compile
```cmd
g++ hospital_html.cpp -o html.exe
```

### Step 2: Generate data
```cmd
html.exe
```

### Step 3: Create dashboard
```cmd
python create_dashboard.py
```

Browser opens automatically with the dashboard!

---

## 🎮 How to Use

**In the browser:**
- Click **"▶ Next Iteration"** - Advance
- Click **"◀ Previous"** - Go back
- Click **"⏯ Auto Play"** - Runs automatically
- Click **"🔄 Reset"** - Start over

**Keyboard shortcuts:**
- **Right Arrow** → Next
- **Left Arrow** → Previous
- **Spacebar** → Auto-play
