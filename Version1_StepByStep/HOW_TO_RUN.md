## 🎯 EASIEST WAY: Just Double-Click!

**Simply double-click:** `RUN.bat`

That's it! The program will:
1. Compile automatically
2. Run automatically
3. Show you the interactive demo

---

## 💻 OR: Manual Method

### Step 1: Compile
```cmd
g++ hospital_interactive.cpp -o interactive.exe
```

### Step 2: Run
```cmd
interactive.exe
```

---

## 🎮 How to Use

1. **Program starts** and shows welcome screen
2. **Press ENTER** to advance each step
3. **Read explanations** about Fibonacci Heap
4. **Press ENTER** to see ML scoring
5. **Press ENTER** to see queue structure
6. **Press ENTER** for each iteration
7. **Explain to your guide** as you go!

---

## ⏱️ Demo Duration

**Your choice!** Take as long as you need - you control the pace with ENTER key.

Typical: 5-10 minutes

## 🆘 Troubleshooting

**Problem:** "g++ is not recognized"
- Install MinGW from: https://winlibs.com/
- Add to PATH: `C:\mingw64\bin`

**Problem:** "Python error"
```cmd
pip install numpy scikit-learn
```
